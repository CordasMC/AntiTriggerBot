## AntiTriggerBot

This plugin isn't maintained, probably doesn't work on the latest version, and shall receive no future updates.
If you wish to build upon it, feel free to fork it.

I built this plugin around 2 years ago as a one-day side-project, and decided "why not show it to the world".
I probably wouldn't make a lot of the decisions now that I made back then, and perhaps I'll re-write this project according
to what I would now consider "good code" in the future.
